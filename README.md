# Mundo Mágico da Antonella — API
Backend HTTPS para história, ilustração por página e narração.

## Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Environment variable obrigatória: `OPENAI_API_KEY`

## Endpoints
- `GET /health`
- `POST /story`
- `POST /image`
- `POST /narration`

Nunca coloque a chave OpenAI no GitHub ou no APK.
